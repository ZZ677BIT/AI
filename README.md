- 出牌后其余手牌平滑补位，停止时不再瞬间跳回。
- 点开、收回、快速切换接着当前显示姿态运动，动画中可以直接出牌。
- 卡牌收回途中可从刚离开的区域再次点回；实际按钮、对话框和场上单位保留优先交互。
- 奖励翻牌采用一次连续旋转，翻牌时暂停漂浮，去掉中途放大和旋转过冲。
- 手机触摸不计算鼠标倾斜；鼠标倾斜按需更新，关闭、后台及关动效时取消任务。

设置 → 开发者测试 → 实战沙盘，可选「20 张手牌 · 滑动压力」直接体验手牌。测试事件「指定卡牌与外观 · 翻牌领奖」可直接体验奖励。卡牌仍需手动翻开、确认入册，下一局由玩家手动开始。
