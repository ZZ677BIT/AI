# 神话手札 v17 · 手机直连测试版

[下载 v17（游戏、操作说明与完整源码）](https://github.com/ZZ677BIT/AI/raw/refs/heads/v17-phone-direct/v17.zip)

**真实双机连通尚未验证。** 云端浏览器管理策略禁用了 WebRTC 直连 UDP 与摄像头。双人规则、界面和二维码图片识别已检查，最终连接需要两部实体手机在同一 Wi-Fi 实测。

全部解压，打开 `01_双击试玩.html`。两部手机使用同一版本，不需要电脑房主或云服务器。

1. 双方进入好友对战，输入昵称，选主将和自己的牌组。
2. 房主生成邀请，好友扫码、导入连接文件或粘贴完整邀请信息。
3. 好友生成回执，房主再导入回执，双方准备后开始。

支持独立换牌、90秒出牌计时、最后15秒提醒、两分钟断线暂停、检查点续局、无掉落结算和双方确认再来一局。二维码库均内嵌。

房主保持游戏前台。刷新或关闭后通常需要重新配对；无服务器时，房主彻底离线无法保证统一仲裁，客机可显示本场中断。

100项检查通过：59项规则、15项使用有序消息测试通道的双浏览器检查、26项地图与单人回归。这不等于实体手机 WebRTC 联机已通过。完整说明与许可证见包内源码文档。

v16和更早版本压缩包保留。
